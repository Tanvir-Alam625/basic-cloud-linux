# Module 01 — AWS EC2 & Linux Fundamentals

This module gets you from zero to a running server on AWS with confidence navigating Linux from the command line.

## Topics

| # | Topic | What You'll Learn |
|---|-------|-------------------|
| 01 | [Intro to EC2](./01-intro-to-ec2/README.md) | What EC2 is, instance types, regions, AMIs |
| 02 | [Launching an EC2 Instance](./02-launching-ec2/README.md) | Launch Ubuntu on AWS Free Tier |
| 03 | [Security Groups & Key Pairs](./03-security-groups-keypairs/README.md) | Control network access, create SSH keys |
| 04 | [SSH Connection](./04-ssh-connection/README.md) | Connect to your server from your machine |
| 05 | [Basic Linux Commands](./05-basic-linux-commands/README.md) | Navigate, create, edit, search files |
| 06 | [Package Manager — apt](./06-package-manager-apt/README.md) | Install and manage software |
| 07 | [Process Manager — systemctl](./07-process-manager-systemctl/README.md) | Start, stop, enable services |

## What You Need

- An AWS Free Tier account
- A terminal with SSH (macOS/Linux: built-in, Windows: Git Bash or Windows Terminal)

## By the End of This Module

You will have a live Ubuntu server on AWS, connected via SSH, with essential tools installed and services running.
